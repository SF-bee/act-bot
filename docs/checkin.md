# 群互动 · 签到

成员每天在群里打卡，机器人记录连续天数与累计次数，并提供群内排行榜。
功能默认**关闭**：先在 `config/config.toml` 的 `[features]` 里打开 `checkin = true`，
再由管理员在各群用 `/config checkin on` 开启（两层开关与其它功能一致）。

## 命令

| 命令 | 别名 | 作用 |
| --- | --- | --- |
| `/签到` | `/checkin`、`/打卡` | 打卡；返回连续天数、累计次数与今日名次 |
| `/签到榜 [本月\|累计]` | `/checkin_rank`、`/签到排行` | 本群排行榜，缺省用 `[checkin].rank_scope` |

- 只能在群里使用；私聊提示「这个命令要在群里用～」。
- 同一天重复 `/签到` 只回「已经签过」，不会重复计数（数据库唯一键 group_id+user_id+date 兜底）。
- `/签到 榜`（或 排行/榜单/排名）等价于 `/签到榜`，习惯写法兜底。
- `/签到榜 xxx` 参数无法识别时只回用法提示，不报错。
- 全局开关关闭时命令**静默不响应**；群级开关关闭时提示让管理员发 `/config checkin on`。

连续天数按自然日回溯（本地时区，最多回看 400 天），断一天即从 1 重新开始；
累计次数是本人本群历史上的打卡总次数，里程碑为 7 / 30 / 100 / 365 天（命中当天用里程碑文案）。

## 配置（`[checkin]`）

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `rank_size` | `10` | 榜单一次显示多少人（1-50） |
| `rank_scope` | `"month"` | 缺省榜单范围：`month`（本月）或 `all`（累计） |
| `daily_text` | 见示例配置 | 打卡成功文案 |
| `repeat_text` | 见示例配置 | 同日重复打卡文案 |
| `milestone_text` | 见示例配置 | 里程碑文案（连续 7/30/100/365 天） |

占位符：`{nickname}`（群昵称，取不到时用打码 QQ）、`{date}`（YYYY-MM-DD）、`{streak}`、
`{total}`、`{rank}`（今日第几个打卡）、`{milestone}`、`{group_name}`、`{bot_name}`、`{bot_title}`。
模板里写错的占位符会原样保留，不会导致发送失败。

## 数据

落地在 `checkins` 表（迁移 `src/core/migrations/007_checkin.sql`）：

| 字段 | 说明 |
| --- | --- |
| `group_id` / `user_id` / `date` | 复合主键，同群同人同一天只有一行 |
| `display_name` | 打卡当时的昵称快照（榜单用它显示，无需回查群昵称） |
| `created_at` | 写入时间（UTC） |

只记录打卡事实，不保存任何消息正文；榜单查询是只读的，不会写库。
逻辑与渲染实现在 `src/core/checkin.py`，命令层在 `src/plugins/checkin/`。
