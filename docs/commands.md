# 命令约定与清单

本文件是命令命名与分层的**唯一约定**。新增命令前先读这里。
`/帮助` 的内容由各插件的 `PluginMetadata` 自动汇总，所以改完命令记得同步 `usage`。

## 一句话约定

- **管理 / 工具型命令：英文**，且只对管理员可见；
- **面向普通成员的功能命令：中文**，追求「看到就会用」；
- 命令前缀永远是 `/`，中文命令也必须带前缀。

为什么不统一？两类命令的受众不同：管理命令由少数人高频输入，英文短、好打、方便脚本化；
成员命令面向全群，中文更直观。这是有意的分层，不是不一致。

## 三条硬规则

### 1. 隐藏 ≠ 安全

普通成员看不到管理命令（`/帮助` 里不显示、直接发也**静默拒绝**），但这只是体验层。
真正的门是 `src/core/permissions.py` 的 `is_admin` 判定：

```python
if not await perms.is_admin(str(event.user_id)):
    await cmd.finish()   # 静默，不暴露命令存在
```

新增管理命令时，这个判断**一次都不能漏**。绝不要把「命令是英文、没写进帮助」当成权限。

### 2. 规范名只有一个，别名用 `aliases=`

```python
stats_cmd = on_command("统计", aliases={"stats"}, priority=10, block=True)
```

- 成员命令：中文规范名 + 英文别名（老习惯不断）；
- 管理命令：只有英文规范名，**不加中文别名**——避免群里随手打中，也保持 CLI 风格。

### 3. 前缀永远非空

`COMMAND_START` 必须是 `/`（或其它非空前缀）。原因：风控与聊天引擎都靠
`text.startswith(command_prefixes())` 来「跳过命令」，空前缀会让它们把所有消息都当命令跳过。
中文命令也一律带 `/`。

## 命令清单

### 面向成员（`role: member`）

| 规范名 | 别名 | 作用 |
| --- | --- | --- |
| `/帮助` | `/help` | 命令帮助菜单；管理员会多看到「管理员命令」一段 |
| `/统计` | `/stats` | 本群活跃概览，可带区间（今天/昨天/本周/上周/本月/近N天）与走势；管理员额外看到命令数、自动回复数、错误数、Top N |
| `/签到` | `/checkin`、`/打卡` | 群内打卡：返回连续天数、累计次数与今日名次；同日重复只提示不重复计数 |
| `/签到榜` | `/checkin_rank`、`/签到排行` | 本群签到排行，可带「本月」或「累计」（缺省看 `[checkin].rank_scope`） |
| `/版本` | `/version` | 版本号与已开启的功能开关数 |
| `/ping` | — | 连通性检查（运维口令，保留英文） |
| `/权限` | `/op` | 查看自己的角色与管理员名单 |

### 面向管理员（`role: admin`，普通成员不可见）

| 命令 | 作用 |
| --- | --- |
| `/config [-g 群号]` | 查看本群功能开关 |
| `/config [-g 群号] <功能> on\|off` | 开关本群功能 |
| `/audit [n]` | 查看最近 N 条管理操作 |
| `/use <群号>` / `/use off` | 私聊管理时绑定 / 解除默认群 |
| `/welcome` | 入群欢迎状态与欢迎语预览（只读） |
| `/chat …` | 聊天规则管理 |
| `/mod …` | 风控规则与状态 |
| `/push` / `/push test <名称>` | 查看 / 试发定时推送（推送本身在 config.toml 的 `[[push]]` 配置） |
| `/warn` `/mute` `/unmute` `/kick` `/recall` | 手动群管理 |

> 管理命令支持**私聊**：先 `/use <群号>` 绑定，或任意命令加 `-g <群号>` 单次指定；
> `-s` 表示静默（群里不发通告，仍写审计）。详见 `docs/moderation.md`。

## 新增命令怎么做

1. 在 `src/plugins/<名字>/__init__.py` 注册：

   ```python
   cmd = on_command("中文名", aliases={"english"}, priority=10, block=True)
   ```

   管理命令则用英文名，并在 handler 首行加 `is_admin` 判定。
2. 在 `PluginMetadata` 里同步 `usage`（一行一个命令，形如 `/cmd — 说明`）与
   `extra["role"]` / `extra["order"]`；
3. 开关类操作**不要**自己写命令，统一走 `/config <功能> on|off`（命令分层约定）；
4. 重启业务层后 `/帮助` 会自动收录，无需改帮助插件。
